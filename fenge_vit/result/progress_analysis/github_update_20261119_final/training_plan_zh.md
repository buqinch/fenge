# 固定配方复现与15／20轮训练对照

目标是用预先确定的训练和选轮规则接近当前水平。当前第15轮完整S为94.3246%，训练结束后由1601验证集自动选出的第19轮为94.2684%，只差0.0561个百分点；这说明常规验证选轮已经接近已测最高成绩。尚无多种子重复，不能把这个小差值确认为稳定退化，也不能保证新运行精确复现94.3246%。

## 先固定可复现的基准

- 模型：DINOv3 ViT-L＋ConvNeXt-Tiny＋双向Adapter＋原UPerNet；两骨干原始预训练初始化。
- 数据：固定同一4000原图＋1000坑增强＋1000山岩增强清单；固定1601张验证，保留来源隔离。3000＋1500＋1500仍是独立数据配比对照，尚未证实更优。
- 有效batch 8。复现首选原单卡batch4、累计2；换双卡4×2需记录，随机数与数值路径不同，不保证逐步一致。
- 前3轮冻结两个骨干；Adapter和解码器正常训练。随后联合训练；骨干基础2e-6、Adapter／解码头1e-4。AdamW、weight_decay0.01、clip1.0、BF16、seed42、poly power0.9。
- 训练20轮，复现时显式保留原30轮学习率衰减跨度。原结果是30轮poly计划运行到20轮，直接改成20轮poly不是同一个复现实验。
- 保留验证BEST与最终权重；每5轮完整2／4／9仅报告，事先固定选轮为1601验证mIoU。相同权重、相同推理协议只评一次。验证仍为1024／768等权翻转，报告测试为1024原图＋水平翻转。

## 预先固定15轮与20轮两组对照

|项目|15轮方案|20轮方案|
|---|---|---|
|训练数据|4000＋1000＋1000|同一清单|
|验证集|固定1601张|同一清单|
|初始化|原始ViT-L＋ConvNeXt预训练|同一来源；不加载已训练分割权重|
|冻结骨干|前3轮|前3轮|
|基础学习率|骨干2e-6；Adapter／解码头1e-4|相同|
|有效batch|8（单卡4×累计2）|相同|
|优化器更新数|11250|15000|
|poly衰减总步数|11250，power0.9|15000，power0.9|
|停止规则|完成15轮，无早停|完成20轮，无早停|
|选轮|固定1601验证mIoU最高轮|相同|
|完整测试|每5轮评测验证BEST|相同|
|测试TTA|1024原图＋水平翻转|相同|

两组只改变预定训练／学习率调度时长与独立输出目录。每组在自己的预算内把学习率衰减到接近0；这比较的是“预算＋对应调度”，不是只多训练5轮。若要严格隔离训练长度，需要两组共享同一衰减曲线，并事先固定15与20轮截点，这应另记一种设计。

现有最高结果使用30轮poly，在第15轮被测到94.3246%；15轮完整衰减不是该历史结果的原样复现，收益未知。现有30轮poly运行至第20轮，倍率约(1-20/30)^0.9=0.372，即骨干约7.44e-7、解码头约3.72e-5，仍未衰减完。新对照用于判断预定预算内更充分衰减能否得到稳定的验证BEST和最终模型。

先比较同一验证规则选出的BEST与最终轮，关注整体mIoU、坑／岩精确率和召回率。若单次对照有收益，再按固定种子42／43／44各重复并报告均值与范围；不要挑最好种子作为唯一结果。若没有明确验证收益，保留已经达到94.2684%的常规方案。

未来还可以独立核对单1024翻转验证选轮与部署推理的一致性，但不要和学习率对照同时修改，否则难以解释变化。本次只整理方案，没有修改正在训练的3000配比运行，也没有启动新的训练。

学习率衰减总步数和幂指数的含义参见[PyTorch PolynomialLR文档](https://docs.pytorch.org/docs/stable/generated/torch.optim.lr_scheduler.PolynomialLR.html)。本项目实际使用自定义PolynomialSchedule，以上数值依据已保存配置和源码计算，不意味着已经更换调度器。
