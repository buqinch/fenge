# 双尺度水平翻转：验证集选择全局融合权重

复用 `dual_region_random80_1024/best.pt`（第 **29** 轮），不重新训练。在完整 1601 张随机划分验证原图上比较 w1024=1、0.75、0.5，全部图片与场景共用同一权重。

先分别将 1024 和 768 尺度的原图、水平翻转连续类别概率还原坐标并求平均，再计算 `P = w1024 × P1024 + (1−w1024) × P768`，最后执行一次 argmax。两个尺度均原尺寸进入两支 CNN；下采样输入使用带抗锯齿的双线性插值。山体 α=1、坑 γ=1。

w1024=1 的整体及每场景整数混淆矩阵已与保存的最佳轮验证逐位核对一致。总体 mIoU 由全部验证像素汇总的五类混淆矩阵计算，未对场景 mIoU 简单平均。

验证推荐为 **w1024=0.75、w768=0.25**。规则为最大化总体验证 mIoU；1e-12 容差内并列时优先较大的 1024 权重。该选择在读取可选测试记录之前完成，不按测试场景分别挑权重。

验证扫描一次遍历，执行 3,204 次网络前向：每批缓存四视图后复用三个候选，并非对每个权重重新运行网络。单独部署 w1024=1 只需 1024 的两视图；其他候选需要四视图。
