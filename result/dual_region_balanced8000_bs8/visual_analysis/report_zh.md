# 保存图片后的分割诊断与下一轮实验建议

主要短板是撞击坑与月壤的双向混淆：既有大坑内部被切成月壤、局部坑壁被分成山体，也有坑区外扩和无坑区域误报。另有已标注岩石整块漏分。部分边缘误差可以做细化，但大区域类别判断同样需要改善。

本报告实际查看原图／GT／预测对照，针对 **无 TTA 训练组第 5 轮最佳权重、单视图推理**。本次没有重新训练模型。另一组 TTA 训练已按要求停止于第 14 个完整轮次，其最佳第 12 轮 Moon_5 mIoU 为 88.4815%；这些图片不是该第 12 轮模型的预测，不能直接据此断言后者的具体错误完全相同，更不能证明 88% 是模型上限。

## 数据与核验

- GPU 3 完整导出 Moon_2 1597、Moon_4 1320、Moon_9 2087 张，共 **5004 张**，每张保存预测 ID、彩色预测、GT ID 与三联对照图，图片目录约 2.7 GiB。
- 重新读取全部保存的 ID 图，重算的总混淆矩阵及三个场景混淆矩阵都与评分 JSON **逐元素完全相等**，也与先前未保存图片时的评估矩阵一致。
- 单视图加权 S 仍为 **87.0732%**；Moon_2/4/9 mIoU 分别为 **91.6714% / 88.6271% / 83.9971%**。这是场景累计像素评分，不是逐图分数平均。
- 全量统计筛出 17 个分场景案例，包含错误、中位和较好样例；同一场景入选样例的时间序号至少相隔 20。额外放大核对下表诊断案例。仅对选例作视觉审查，没有声称人工逐一看完全部 5004 张。
- 错误选例通常要求相应 GT 类别至少占图像 1%；假坑选例改用预测坑面积至少 0.5%，允许 GT 无坑。Moon_4 没有满足面积与误差门槛的坑山混淆候选，未降低条件凑满 18 例。这些是诊断样例，不能当作错误发生率的随机估计。

## 建议的四个单因素对照

1. **优先调整训练样本覆盖，兼顾完整坑和相似地面负例。** 保留 5000 原始＋1500 大坑＋1500 山岩的总配比，在训练场景中按坑面积、是否触边、阴影强弱、坑内岩石分层选样；从原始样本中覆盖“阴影／凹凸地面但 GT 无坑”的难负例及孤立岩石。继续保存随机种子与完整选择清单。当前是组内随机抽样，并非完全缺少完整坑或非触边坑；目标是使不同困难条件的覆盖可控。先只改采样，验证 Moon_5 的坑精确率、召回率和孤立岩石表现能否同时改善。
2. **保持总点数，先试增强小类别的区域监督。** 区域损失已有每类保底采样，当前 4096 点中每个出现类别最多保底 64 点。可先做 64→256 的独立对照，总点数保持 4096，其余仍均匀采样；先看坑和岩石的 P/R，再决定是否引入不确定性采样。当前代码已有全分辨率 CE＋Dice，不能把这项描述为“首次增加全图监督”。这些参数改动只是实验建议，尚未实施，也不保证收益。
3. **补同条件的双 CNN 像素头对照，验证区域解码方案的净收益。** 用同一份 8000 清单、1024 输入、batch 8、骨干初始化及学习率计划，单独比较 pixel 与 region。当前语义标注每个出现类别只提供一张目标掩码，32 个 query 并不对应 32 个真实坑或岩石实例；图中的完整岩石漏分和坑内碎裂需要通过对照确认改进方向。此对照同时改变解码结构与相应集合损失，应称整体解码方案对照，不能把差异只归因于注意力。
4. **边界细化放在有针对性的第二阶段。** 对“内部基本正确、边缘收缩”的样例，可单独尝试坑／岩石 GT 边界两侧约 3 像素带的 dense CE 权重 2，并按权重总和归一化；这能检验边界监督是否有帮助。案例 A 内部召回仅 40.78%，因此边界指标变好不能替代完整区域分类改善。现有 MobileNet 的 1/4、1/8 细节连接已经接入，不能重复把“增加浅层连接”当成未实现的新方案。

建议执行顺序为：样本覆盖对照 → 小类别点采样对照 → 像素头对照；边界加权只作为独立补充。每次只改一项。先从训练场景构造样本、以完整 Moon_5 评估，Moon_2/4/9 不加入训练或用于选轮。上述建议由测试诊断提出，其效果仍需要新的验证实验，不能预先宣称能突破当前成绩。

保持可比性时还要保留原 30 轮学习率调度预算：train.py 的总更新次数取决于 epochs，直接把新实验 epochs 改成 9 会改变整条 poly 学习率曲线。若比较前九轮，应保留相同调度预算并比较相同更新次数；更完整的结论需统一停止策略并做不同种子复验。
