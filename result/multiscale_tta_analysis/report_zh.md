# 同一检查点的多尺度水平翻转测试

本次复用 `dual_region_random80_1024/best.pt`（第 **29** 轮），没有重新训练。该轮由完整 1601 张随机划分验证集的总 mIoU 选择，验证 mIoU 为 97.5166%；两种新增多尺度 TTA 由用户直接指定在测试集比较，未通过验证集选择这两种模式。

检查点 SHA256：`ed1e2096ccd3be31b7ba40ac07c4dbd7849ed1823cb942f4b802706fe1cc6828`。四种方式均覆盖完整 Moon_2/4/9 共 5004 张（1597/1320/2087），数据身份和各场景每类真值像素数一致。指标由整数混淆矩阵独立重算。

每个尺度使用原图和水平翻转两次前向，翻转预测先还原到原坐标；连续类别概率恢复到 1024×1024 后等权平均，最后执行一次 argmax。1024、768、512 均原尺寸输入两支 CNN，无补边或替代尺寸；山体缩放 α=1。
